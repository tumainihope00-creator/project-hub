Project Hub icon - notes
=========================

Current file: assets\project-hub.ico
Status: FINAL multi-size icon (16/24/32/48/64/128/256 px, PNG-compressed
frames) matching the product logo: a rounded accent-blue tile with three
ascending bars — Capture. Build. Ship.

Source of truth:
  - Vector logo: frontend/public/logo.svg (and favicon.svg for the browser)
  - In-app component: frontend/src/components/Logo.tsx
  - Regenerator: scripts\generate-icon.ps1 (draws the same geometry with GDI+
    and packs the multi-size .ico). Re-run it after changing logo geometry:

      powershell -NoProfile -ExecutionPolicy Bypass -File scripts\generate-icon.ps1

Usage:
  - Desktop shortcut: scripts\create-shortcut.ps1 already points the "Project
    Hub" shortcut at this .ico.
  - Future desktop packaging (Electron/Tauri or similar) should use this same
    file as the application icon.

Colours: tile #2563eb, bars #ffffff (fixed brand colours, independent of the
in-app theme; the in-app logo adapts to the active theme via CSS tokens).
