Project Hub icon - notes
=========================

Current file: assets\project-hub.ico
Status: placeholder, generated by scripts\generate-icon.ps1 (single-size, dark
hub/reticle motif in the app colors).

Required for a FINAL icon:
  - Format: Windows ICO file (.ico). Do NOT use .png/.jpg/.svg for the shortcut icon.
  - Sizes: include multiple resolutions for crisp rendering at every scale:
      16x16, 24x24, 32x32, 48x48, 64x64, 128x128, 256x256
  - Optional 8-bit alpha; must be square.
  - Background should stay dark (#0d1117) to match the app UI, or be fully transparent
    if you prefer a transparent icon.

To replace it: drop a multi-size .ico at assets\project-hub.ico, then update the desktop
shortcut (right-click "Project Hub" > Properties > Change Icon > Browse to the .ico, or
delete the shortcut and re-run scripts\create-shortcut.ps1).
